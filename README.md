# 🧠 Brain Tumor Detection

## 🚀 Project Overview

This project is a Deep Learning-based Brain Tumor Detection system using Convolutional Neural Networks (CNN). It allows users to upload brain CT Scan images and predicts the presence of a tumor using a trained Keras model.

## 🧠 Features

- Upload MRI images and detect tumors
- Utilizes a trained CNN model (.keras file)
- Simple web interface built with Python
- Modular design with Flask-style Python scripts

## 🛠️ Tech Stack

- Python
- TensorFlow / Keras
- OpenCV / PIL
- Flask (or streamlit if applicable)
- Jupyter Notebook
- Git & GitHub

## 🧪 How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/sanapsagar2002/Brain-Tumor-Detection.git
cd Brain-Tumor-Detection

2. Install Requirements

pip install -r requirements.txt

3. Run the App

python app.py

🧠 Model Info

The CNN was trained using CT Scan images and achieved high accuracy (~92%). The .keras model file is loaded for real-time inference on uploaded images.
